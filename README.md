# PixelPad

Ein einfaches Pixelgrafik-Zeichenprogramm (Paint-Klon) für den Unterricht – läuft komplett im Browser, auch auf dem iPad, ohne Login.

**Funktionen:** Stift, Radierer, Sprühdose, Farbeimer, Pipette, Linie, Rechteck, Ellipse, Text · zwei Farben (Stift/Rand und Fläche) · Rückgängig/Wiederholen · Zoom · Bilder öffnen · Speichern als PNG oder JPG · automatische Zwischenspeicherung im Browser.

Die ganze App steckt in `index.html`.
